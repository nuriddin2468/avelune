# 0073. Link: a native link, always underlined, that says when it opens a new tab

- Status: Accepted (2026-09-29; the underline chosen by the product owner, the rest a technical decision within Wave 4)
- Date: 2026-09-29
- Related: 0023, 0033, 0037, 0047, 0061; brief §9.1, §9.4; WCAG 1.4.1, 3.2.5 (G201)

## Context

Brief §9.4 lists Link in Wave 4; brief §9.1 enhances native elements with attribute selectors. Facts, verified on 2026-09-29 (Angular 22.2.0, Chromium 153):

- `base.css` colours every `<a>` `fg.link` (orange 600 in light); `fg.link` passes 4.5:1 on every surface and every tinted fill (`contrast-pairs.json`). Against body text it is under 3:1, so a link inside text needs more than its colour (WCAG 1.4.1).
- `avelune/no-raw-elements` checks consumers' `<a>` nowhere yet; `a[aveButton]` is the kit's link that looks like a button (ADR 0037). Breadcrumbs and the sidebar navigation draw their own links (ADR 0070, 0072).
- A link that opens a new tab should say so before it is followed (WCAG technique G201). A link's static `target` attribute can be read once, with `HostAttributeToken`.
- There is no token for an underline's offset; `border-width.default` and `border-width.selected` are 1 and 2px.

## Decision

1. **`@avelune/ui/link`** (layer components), `AveLink` on `a[aveLink]`: no inputs. The link keeps its native role, keyboard and `href`, and works with `routerLink`.
2. **Look (product owner, 2026-09-29):** `fg.link`, always underlined, in text and outside it, the underline `border-width.default` thick at the font's own offset and `border-width.selected` under the pointer; the font of the text around it; the kit's ring with `radius.sm`. Forced colours give it the system's link colour.
3. **A new tab:** a link with `target="_blank"` shows Lucide's `external-link` after its words, 4px from them, named in the locale (`opensInNewTab`, "откроется в новой вкладке"), so its name says it.
4. **`a` joins `avelune/no-raw-elements`** with `aveButton`, `aveIconButton` and `aveLink`: an application's link is a kit link. The breadcrumbs' and the navigation's links are the kit's own.
5. **Harness:** `AveLinkHarness` (`@avelune/ui/link/testing`): the words, the address, whether it opens a new tab, following it.

## Alternatives considered

- **Underlined only under the pointer outside text** (a "standalone" variant): the product owner chose one rule everywhere.
- **A colour change on hover:** `fg.link` has no hover role, and a darker orange would be a fill token used as text; the thicker underline is the change.
- **A visited colour:** work systems revisit the same records all day; a second link colour would mark most of them.
- **Styling `a` in `base.css` alone:** the ring's radius, the new tab's icon and its words need a component; `base.css` keeps the colour for the text of markdown and third-party content.

## Consequences

- Every link of an application needs `aveLink` or `aveButton`; the showcase's register links its contracts with `aveLink`, and its expired-contract alert and a contract's approval tab link inside their text.
- A link whose `target` is bound (`[target]`) is not seen as opening a new tab; write the attribute.
