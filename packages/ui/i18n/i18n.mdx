# Messages and formats

`@avelune/ui/i18n` holds the words the kit's components say themselves (`AveMessages`) and the formats of dates, numbers and file sizes, in four locales: Russian, English, Uzbek in Latin script and Uzbek in Cyrillic (ADR 0047, ADR 0048, ADR 0050). The application's `LOCALE_ID` picks the locale; `provideAveMessages()` replaces any message; `injectAveMessages()` reads them.

## Setup

```ts
import { ApplicationConfig, LOCALE_ID } from '@angular/core';
import { provideAvelune } from '@avelune/ui/theme';
import { provideAveMessages } from '@avelune/ui/i18n';

export const appConfig: ApplicationConfig = {
  providers: [
    provideAvelune(),
    { provide: LOCALE_ID, useValue: 'ru' },
    provideAveMessages({ noResults: 'Контрагент не найден' }),
  ],
};
```

## When to use

- Always set `LOCALE_ID` to the application's locale: components choose their words and their date, number and file-size formats from it.
- Use `provideAveMessages()` for a wording of the product's own ("Контрагент не найден" instead of "Ничего не найдено"), or for a locale the kit does not ship.
- Use the format functions wherever the product shows a date, a number or a file size that a kit component also shows, so both read alike.

## When not to use

- Not for the product's own texts: they belong to the application's translation system. `AveMessages` holds only what kit components say.
- Not to write dates with `toLocaleDateString` where a kit calendar shows the same date: Chromium has no data for Uzbek in Latin script and writes `2026 M09 23`. `aveDateFormat()` and `aveNumberFormat()` write it right.

## The messages

`AveMessages` is an interface of read-only members: a string, or a function that takes the values a sentence needs and returns a string. The kit ships four full sets:

- `aveMessagesRu`: Russian.
- `aveMessagesEn`: English, the fallback for any locale the kit does not know.
- `aveMessagesUzLatn`: Uzbek, Latin script.
- `aveMessagesUzCyrl`: Uzbek, Cyrillic script.

`aveMessagesFor(locale: string): AveMessages` returns the set for a BCP 47 tag: Russian for `ru` and its regions, Uzbek in Cyrillic for `uz-Cyrl`, Uzbek in Latin script for any other `uz`, English otherwise.

`provideAveMessages(messages: Partial<AveMessages>): Provider` replaces some of them. Put it in the application's, a route's or a component's providers; the nearest one wins as a whole (an outer one is not merged in), over the kit's messages for `LOCALE_ID`. A message you do not name stays as the kit says it. For a locale the kit does not ship, English fills what you do not name, so list every message you want in that language:

```ts
import { LOCALE_ID } from '@angular/core';
import { provideAveMessages, type AveMessages } from '@avelune/ui/i18n';

const kazakh: Partial<AveMessages> = { noResults: 'Ештеңе табылмады', cancel: 'Бас тарту' };

export const providers = [
  { provide: LOCALE_ID, useValue: 'kk' },
  // Messages the set does not name fall back to English through aveMessagesFor('kk').
  provideAveMessages(kazakh),
];
```

`injectAveMessages(): AveMessages` returns the messages for the caller's injector: the kit's for `LOCALE_ID`, with the nearest `provideAveMessages()` over them. Call it in an injection context.

```ts
import { ChangeDetectionStrategy, Component } from '@angular/core';
import { injectAveMessages } from '@avelune/ui/i18n';

@Component({
  selector: 'app-upload-hint',
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `<p>{{ messages.tooManyFiles(3) }}</p>`,
})
export class UploadHint {
  protected readonly messages = injectAveMessages();
}
```

## Dates

A date without a time or a time zone is an `AvePlainDate`: an ISO 8601 string such as `2026-09-23`. It survives JSON and time zones unchanged, and it is the value of the date picker.

- `toPlainDate(year, month, day): AvePlainDate` builds one from its parts (month 1 to 12): `toPlainDate(2026, 9, 23)` is `'2026-09-23'`.
- `plainDateParts(date): { year: number; month: number; day: number } | null` reads one back. It returns `null` when the string is not an ISO date or not a real date: `plainDateParts('2026-02-30')` is `null`.
- `aveDateFormat(locale: string): AveDateFormat` returns how dates are written and named in a locale. Uzbek in Latin script is written by the kit itself, from CLDR.

`AveDateFormat` has these fields:

| Field                    | Type                                                           | What it is                                                                                                                                                         |
| ------------------------ | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `locale`                 | `string`                                                       | The locale the format is for.                                                                                                                                      |
| `firstDayOfWeek`         | `1 \| 2 \| 3 \| 4 \| 5 \| 6 \| 7`                              | The first day of the week: 1 is Monday, 7 is Sunday. Sunday for English in the United States (and English without a region), Monday for the rest.                  |
| `weekdays`               | `readonly { readonly long: string; readonly short: string }[]` | The weekday names, Sunday first: in full ("понедельник") and abbreviated with a capital ("Пн").                                                                    |
| `months`                 | `readonly string[]`                                            | The month names as they stand alone, January first, with a capital ("Сентябрь").                                                                                   |
| `placeholder`            | `string`                                                       | What a date field shows while empty: the order and the separators, in the locale's letters ("дд.мм.гггг").                                                         |
| `numeric(date)`          | `(date: AvePlainDate) => string`                               | A date as people type it: `23.09.2026` (ru), `23/09/2026` (uz), `09/23/2026` (en).                                                                                 |
| `long(date)`             | `(date: AvePlainDate) => string`                               | A date in words: "23 сентября 2026 г.", "23-sentabr, 2026", "September 23, 2026".                                                                                  |
| `monthYear(year, month)` | `(year: number, month: number) => string`                      | A month and its year, as a calendar's heading: "Сентябрь 2026 г.", "Sentabr, 2026".                                                                                |
| `parse(text)`            | `(text: string) => AvePlainDate \| null`                       | Reads a typed date in the locale's order, with any of `.`, `/`, `-` or a space between the parts, and a two-digit year as 20xx. `null` when it is not a real date. |

```ts
import { aveDateFormat, plainDateParts, toPlainDate } from '@avelune/ui/i18n';

const ru = aveDateFormat('ru');
const date = toPlainDate(2026, 9, 23); // '2026-09-23'

ru.numeric(date); // '23.09.2026'
ru.long(date); // '23 сентября 2026 г.'
ru.monthYear(2026, 9); // 'Сентябрь 2026 г.'
ru.placeholder; // 'дд.мм.гггг'
ru.parse('23.9.26'); // '2026-09-23'
ru.parse('31.02.2026'); // null
aveDateFormat('en').numeric(date); // '09/23/2026'
plainDateParts(date); // { year: 2026, month: 9, day: 23 }
```

## Numbers

`aveNumberFormat(locale: string, options?: Intl.NumberFormatOptions): Intl.NumberFormat` is `Intl.NumberFormat` with Uzbek in Latin script written right: plain numbers and percentages in it use the symbols of Uzbek in Cyrillic, which are the same in every browser. Other styles (currency, units) keep the locale.

```ts
import { aveNumberFormat } from '@avelune/ui/i18n';

aveNumberFormat('uz-Latn', { maximumFractionDigits: 1 }).format(1234.56); // '1\u00a0234,6'
aveNumberFormat('ru').format(1234567.8); // '1\u00a0234\u00a0567,8'
```

## File sizes

`aveFileSize(bytes: number, locale: string): string` writes a file size as people read it: bytes, kilobytes, megabytes or gigabytes of 1024, with one decimal under 10 and none above, and a no-break space before the unit. Russian and Uzbek in Cyrillic use `Б`, `кБ`, `МБ`, `ГБ`; the other locales use `B`, `kB`, `MB`, `GB`. A negative size is written as 0 bytes.

```ts
import { aveFileSize } from '@avelune/ui/i18n';

aveFileSize(2_516_582, 'ru'); // '2,4\u00a0МБ'
aveFileSize(2_516_582, 'uz-Latn'); // '2,4\u00a0MB'
aveFileSize(2_516_582, 'en'); // '2.4\u00a0MB'
aveFileSize(512, 'ru'); // '512\u00a0Б'
```

## Keyboard and accessibility

This entry point has no interface of its own, so it has no keyboard behaviour. Messages are what screen readers hear: the names of buttons and landmarks, and the sentences said after a list loads or files are attached. A replacement keeps each message's job, as the table says: a name that stands before a value ("Удалить «Договор.pdf»") must still read well with it.
