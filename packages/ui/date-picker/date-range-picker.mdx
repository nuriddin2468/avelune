# DateRangePicker

`<ave-date-range-picker>` is a period: two inputs for its first and last date and one calendar in which the first choice sets the start and the second the end (ADR 0048).

```ts
import { AveDateRangePicker, type AveDateRange } from '@avelune/ui/date-picker';
```

<Canvas of={DateRangePickerStories.Default} />

## When to use

- For two dates that make one period: a contract's term, a report's range, a leave.

## When not to use

- For one date: a DatePicker. For two unrelated dates: two DatePickers, each with its label.

## Anatomy

The start input, a dash, and the end input with the calendar button, in two equal columns; each has the box of an Input. A range that can be cleared has a wider end input, with the clear button before the calendar button (see Clearing). In the calendar, the range's ends have the accent fill and the days between a light accent tint.

```html
<ave-form-field label="Срок действия">
  <ave-date-range-picker [formField]="contract.term" />
</ave-form-field>
```

<Canvas of={DateRangePickerStories.Open} />

## Choosing

- The first day chosen in the calendar sets the start and keeps the calendar open; the second sets the end and closes it. A day before the start begins the range again.
- Typed dates are read as in a DatePicker; an end typed before the start swaps them.
- The heading opens the months, then the years, as in a DatePicker (ADR 0053); they only move the calendar, and the range is still chosen among the days.

## Presets

For the periods people ask for again and again, `presets` puts a list of them in the calendar's panel (ADR 0054): the kit's own, by name, in the application's language, and the application's own, with their label and dates. None are shown unless the application asks.

A preset is an `AveDateRangePreset`: either an `AveDateRangePresetName`, one of the names in the table below, or an `AveDateRangeCustomPreset`, an object with a `label` (what the preset says, in the application's language), a `start` and an `end` (ISO dates, the end never before the start).

```ts
import type { AveDateRangePreset } from '@avelune/ui/date-picker';

readonly periods: AveDateRangePreset[] = [
  'today',
  'thisWeek',
  'lastMonth',
  'last30Days',
  { label: 'Первое полугодие', start: '2026-01-01', end: '2026-06-30' },
];
```

```html
<ave-date-range-picker [presets]="periods" [formField]="report.period" />
```

| Name          | Period (on Thursday 24.09.2026, weeks from Monday) |
| ------------- | -------------------------------------------------- |
| `today`       | 24.09.2026                                         |
| `yesterday`   | 23.09.2026                                         |
| `thisWeek`    | 21.09.2026 – 27.09.2026                            |
| `lastWeek`    | 14.09.2026 – 20.09.2026                            |
| `thisMonth`   | 01.09.2026 – 30.09.2026                            |
| `lastMonth`   | 01.08.2026 – 31.08.2026                            |
| `thisQuarter` | 01.07.2026 – 30.09.2026                            |
| `thisYear`    | 01.01.2026 – 31.12.2026                            |
| `last7Days`   | 18.09.2026 – 24.09.2026                            |
| `last30Days`  | 26.08.2026 – 24.09.2026                            |

- Weeks start on the locale's first day: Monday in Russian and Uzbek, Sunday in American English. Periods are whole: this month ends on its last day; the last 7 and 30 days end today.
- Choosing a preset sets the range and closes the calendar. The preset whose period is the range chosen now has a check; when two presets have the same period (this year cut to this month's bounds), the one chosen keeps it.
- `minDate` and `maxDate` cut a preset to them; one with no day inside them is shown, disabled.
- From a window of 600px the list stands beside the calendar; in a narrower window it stands above it, four presets tall, and scrolls.

## States

<Canvas of={DateRangePickerStories.States} />

As a DatePicker's: invalid is a red border on both inputs, readonly a dashed border on a sunken fill, disabled a flat fill.

## Clearing

A range that is not required shows a clear button before the calendar button, in the end input, while either date is there and it can be changed (ADR 0052). A press empties both inputs (the value becomes `null`), closes the calendar and moves focus to the start input. On the keyboard, deleting both dates does the same; the button is not a Tab stop.

The end input of a range that can be cleared is wider, by the room of the clear button, whether or not a date is there: both inputs have the same room for their dates, which show in full down to 320px, and nothing moves when a date arrives. A required, readonly or disabled range keeps two equal inputs.

<Canvas of={DateRangePickerStories.Clearing} />

## Value

`{ start, end }` of ISO dates, either of which may be `null` while it is missing; the value is `null` while both are, so `required` works. A rule such as "the end is required" is the application's, in its schema.

## Narrow containers

Two dates side by side need 320px (`container.xs`), with or without the clear button. In a narrower container, such as a form column on a 320px phone, the end input goes under the start input and the dash is left out; the inputs keep their names.

## Keyboard

As a DatePicker's, for each input and for the calendar. In the presets, the arrow keys move, Home and End go to the first and last, typing a letter moves to the next preset that starts with it, and Enter or Space choose; the list is one Tab stop before the calendar.

## Accessibility

- Each input is named by the field's label and its part: "Срок действия, Дата начала" and "…, Дата окончания" (`aria-labelledby`); both are described by the field's hint and error. Without an `<ave-form-field>`, the `label` input takes the field's place in the names.
- The clear button is named "Clear" and the field's label ("Очистить Срок действия"); it is left out of the Tab order.
- The presets are a listbox named "Периоды" in the locale; the checked preset is `aria-selected`, a preset outside the bounds `aria-disabled`.

## Motion

As a DatePicker's.

## Do and don't

- Do label the field with what the period is ("Срок действия"), not with "From – To".
