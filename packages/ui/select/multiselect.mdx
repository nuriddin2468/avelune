# Multiselect

`<ave-multiselect>` is several choices from a list, under a trigger that shows each chosen value as a tag. The list stays open while people check and uncheck options. It is Angular Aria's combobox with a multi-select listbox, in CDK's overlay (ADR 0046).

```ts
import { AveMultiselect, type AveOption } from '@avelune/ui/select';
```

<Canvas of={MultiselectStories.Default} />
<Controls />

## When to use

- For several choices from 6 to 15 options, where space is short: approvers, regions, document types in a filter.

## When not to use

- For 2 to 5 options: checkboxes in a `fieldset[aveChoiceGroup]`, all visible.
- For one choice: a select.

## Anatomy

A trigger with the box of an Input and a chevron; inside it, each chosen value as a small tag (ADR 0081), in rows that wrap 4px apart, or the placeholder while nothing is chosen. The field grows by a row of tags. The list is the select's, with a check on every chosen option.

```html
<ave-form-field label="Согласующие">
  <ave-multiselect [options]="approvers" placeholder="Выберите согласующих" [formField]="contract.approvers" />
</ave-form-field>
```

<Canvas of={MultiselectStories.Open} />

## Tags

Each chosen value is a tag (`sm`, ADR 0080) inside the field. Its remove button unchecks it and puts focus on the trigger; the buttons are not Tab stops, since the keyboard unchecks in the list, and a disabled or readonly multiselect's tags have none. A press on a tag's words opens the list, as a press anywhere in the field does. The trigger still says the chosen labels to screen readers, out of sight.

## Rich options

Options take the same fields (`value`, `label`, `disabled`, `description`, `icon` or `image`, `meta`) and templates (`<ng-template aveOption [aveOptionOf]="options" let-option>`) as a select's (ADR 0055); the tags show the chosen labels, as text.

<Canvas of={MultiselectStories.RichOptions} />

## Search

For long lists, `search="local"` makes the trigger an input (ADR 0057): people type after the last tag (or on a row of their own when the last row is full), and the options are filtered by label, as a combobox does. Checking an option keeps the search and the list open; closing the list or leaving ends the search. The input is described by what is chosen ("Выбрано: город Ташкент", ADR 0081). `search="server"` asks a server instead, with the combobox's `query`, `loading`, `error`, `hasMore` and `loadMore` (ADR 0056).

```html
<ave-form-field label="Регионы поставки">
  <ave-multiselect
    search="local"
    [options]="regions"
    placeholder="Начните вводить регион"
    [formField]="contract.regions"
  />
</ave-form-field>
```

<Canvas of={MultiselectStories.Search} />

- Down opens the list; Enter checks or unchecks the active option; Space types; Escape closes.
- Deleting the text clears the search, not the choices: uncheck them in the list, or all of them with the clear button.

## States

<Canvas of={MultiselectStories.States} />

As the select: invalid, readonly and disabled on the trigger; disabled options dimmed.

## Clearing

A multiselect that is not required shows a clear button before the chevron while at least one option is chosen and it can be changed (ADR 0052). A press unchecks every option (`[]`), closes the list and leaves focus on the trigger; Delete or Backspace on the trigger do the same. One option is unchecked in the list.

## Forms

<Canvas of={MultiselectStories.Forms} />

The value is an array (`V[]`), empty while nothing is chosen, always in the order of the options. To ask for at least one, Signal Forms need `minLength(path.approvers, 1)`: their `required` accepts an empty array. The field then shows as required too (ADR 0049). Reactive Forms' `Validators.required` already fails on an empty array.

## Chosen options outside the list

When the options change and no longer hold the value (a list the application loads anew), the value stays chosen (ADR 0056). `chosenOptions` gives the options of a value the application sets, so the trigger can name them; the options people choose are remembered.

## Content

The tags wrap in rows and a long label wraps inside its tag; nothing is cut.

<Canvas of={MultiselectStories.LongText} />

## Keyboard

Tab moves to the trigger; Down, Enter or Space open the list; the arrow keys move; Enter or Space check or uncheck the active option; Escape or Tab close the list. Delete or Backspace on the trigger uncheck every option of a multiselect that is not required. With `search`, the trigger is an input: typing searches, Enter checks, Space types.

## Accessibility

- The list is `aria-multiselectable`; each option says whether it is selected.
- The trigger is named by the field's label; its text lists what is chosen, out of sight while the tags show it; a searchable input is described by it.
- Each tag's remove button is named "Убрать" and the value ("Убрать Юридический отдел"); it is left out of the Tab order, as the clear button is.
- The clear button is named "Clear" and the field's label; it is left out of the Tab order.

## Motion

As the select.

## Do and don't

- Do keep the number of options small enough to scan.
- Don't use a multiselect where people need to see every choice at once; use checkboxes.
