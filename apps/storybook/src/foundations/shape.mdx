# Radius and elevation

Radii follow the hierarchy of elements, and nested corners are concentric: an inner radius equals the outer radius minus the gap between them. Four elevation levels are each a two-layer shadow; overlays carry a subtle border in both themes, and in the dark theme higher surfaces are also lighter.

## Using shape

- Assign a radius by the element's rank, never one radius for everything: `radius.sm` for small parts (a checkbox, a tag, a badge), `radius.md` and `radius.lg` for controls, panels and overlays, `radius.full` for anything fully round.
- Elevation is `box-shadow: var(--ave-elevation-popover)`. Use the level of the element's role: `flat` for content on the page, `raised` for cards that lift, `popover` for menus and popovers, `dialog` for dialogs.
- `border-width.default` is the hairline of borders and dividers; `border-width.selected` marks a selected item.
- `z-index.*` orders elements outside the top layer, in one sequence. A native `<dialog>` and `[popover]` render in the top layer and ignore `z-index`.
- Write every value as a token: `border-radius: var(--ave-radius-md)`. Never a raw pixel, shadow or z-index number.

## Token reference

### Radius (`radius`)

{/* tokens:radius */}

| Token         | CSS variable        | Value    | Description                                                       |
| ------------- | ------------------- | -------- | ----------------------------------------------------------------- |
| `radius.sm`   | `--ave-radius-sm`   | `4px`    | Small parts: checkbox, tag, badge, items nested inside a control. |
| `radius.md`   | `--ave-radius-md`   | `8px`    | Controls and the items of menus and lists.                        |
| `radius.lg`   | `--ave-radius-lg`   | `12px`   | Containers: card, popover, menu, dialog, drawer.                  |
| `radius.full` | `--ave-radius-full` | `9999px` | Pills, avatars, switch tracks.                                    |

{/* /tokens */}

### Border width (`border-width`)

{/* tokens:border-width */}

| Token                   | CSS variable                  | Value | Description              |
| ----------------------- | ----------------------------- | ----- | ------------------------ |
| `border-width.default`  | `--ave-border-width-default`  | `1px` |                          |
| `border-width.selected` | `--ave-border-width-selected` | `2px` | Selected cards and tabs. |

{/* /tokens */}

### Elevation (`elevation`)

{/* tokens:elevation */}

| Token               | CSS variable              | Value                                                           | Dark                                                            | Description                                                  |
| ------------------- | ------------------------- | --------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------ |

| `elevation.popover` | `--ave-elevation-popover` | `0px 2px 4px 0px #1e1b1a14,`<br />`0px 8px 16px 0px #1e1b1a1f`  | `0px 2px 4px 0px #1e1b1a52,`<br />`0px 8px 16px 0px #1e1b1a7a`  | Level 2: menus, popovers, select popups, tooltips.           |
