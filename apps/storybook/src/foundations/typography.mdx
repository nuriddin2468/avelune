# Typography

Twelve text styles on Avelune Sans (IBM Plex Sans), with Avelune Mono (IBM Plex Mono) for code (ADR 0018). Body text is 14/20, every line height is a multiple of 4, and there are three weights: 400, 500 and 600. The fonts cover Latin, Cyrillic and Uzbek Latin and Cyrillic.

## Using type

- A text style is one custom property that holds the whole `font` shorthand: `font: var(--ave-font-body-md)`. Add its letter spacing separately: `letter-spacing: var(--ave-font-body-md-letter-spacing)`.
- `tokens.css` also gives each style's parts, for a case where only one is needed: `--ave-font-body-md-family`, `--ave-font-body-md-size`, `--ave-font-body-md-weight`, `--ave-font-body-md-line-height` and `--ave-font-body-md-letter-spacing`. The same suffixes exist for every style.
- Pick the style by its role: `display` once per screen at most, `heading-*` for titles, `body-*` for reading text, `label-*` for controls and fields, `caption` for hints and timestamps, `code` for identifiers and logs.
- Plain HTML already takes the right style from the global stylesheet: `h1` to `h4` map to the heading styles, `p` to `body-md`, `pre` to `code` (see Foundations/Global styles). Use a token only when an element needs a style its tag does not give.
- Never write a raw font size, weight or family.
