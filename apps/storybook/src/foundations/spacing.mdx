# Spacing and size

A 4px grid. Spacing tokens are named by their multiple: `space.4` is 16px, and they are the only semantic tokens with numbers in their names. Control heights and paddings come through component tokens, so compact density changes them without any change in your CSS.

## Using space and size

- Related elements sit 8px apart (`space.2`), form fields 16px (`space.4`), sections 32 to 48px (`space.8` to `space.12`).
- Write spacing as `padding: var(--ave-space-4)` or `gap: var(--ave-space-2)`. Never a raw pixel value.
- `size.control.*` are control heights, `size.icon.*` are icon boxes and `size.target.*` are hit areas; the smallest target of anything interactive is `size.target.min`.
- `control.height.*` and `control.padding-inline.*` are what kit controls read; they follow density. Use them for an own control that must line up with kit controls of the same size.
- `container.*` are widths where a component changes its own layout (container queries). `breakpoint.*` are widths where the page layout changes. CSS cannot read a custom property inside a media or container query, so use these values through the typed tokens and a lint check, not as ad-hoc numbers.

### Sizes (`size`)

| Token                | CSS variable               | Value  | Description                                        |

| `size.control.sm`    | `--ave-size-control-sm`    | `32px` |                                                    |
| `size.control.md`    | `--ave-size-control-md`    | `36px` | The default control height for 14/20 text.         |

| `size.icon.sm`       | `--ave-size-icon-sm`       | `16px` |                                                    |
