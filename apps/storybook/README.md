# Storybook

Foundations pages (Phase 2), and from Phase 3 component docs, stories, interaction and a11y tests, on `@storybook/angular-vite` (ADR 0008).

- `pnpm nx serve storybook`: builds the tokens, serves on http://127.0.0.1:6006.
- `pnpm nx build storybook`: static build in `dist/apps/storybook`.

See "Storybook" in [ARCHITECTURE.md](../../docs/ARCHITECTURE.md).
